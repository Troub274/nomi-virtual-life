Using Direct Chat

Select two connected conversation tabs (ChatGPT or Nomi). Tab 1 is the controller; Tab 2 is the peer. Press Play. The bridge sends startup instructions to Tab 1. Only a new completed Tab 1 assistant response containing [bridge send] sends text to Tab 2; ordinary assistant responses remain private.

Tab 1 commands: [bridge send] followed by text, [bridge pause], [bridge resume], and [bridge shutdown]. Use a single command per assistant response. [bridge status] and [bridge pending] report bridge state. Do not use API-room commands here.

The bridge waits for each completed peer reply before delivering another turn. Nomi browser messages are capped at 750 UTF-8 bytes. Never assume an uncertain send failed; inspect both chats before restarting.

Using Group Room

Select a ChatGPT tab first and a Nomi browser group-room tab second, then press Play. The bridge supplies GPT's group protocol and current room observations automatically.

[say] followed by text posts into the group; [listening] or [wait] observes; [invite] followed by an exact member name selects a speaker; [play] and [pause] control room Auto Chat. [help] retrieves group instructions. Group messages are split into chunks rather than truncated. Do not use [bridge send] or [say room] in Group Room mode.

Using Nomi API Room

Save your Nomi API key, refresh the Nomi/room lists, select one Nomi and a persistent room containing only that Nomi. Select ONE ChatGPT tab above, then press Play. No Nomi browser tab is required. A currently visible GPT reply is a baseline; prompt GPT to produce a NEW assistant reply after Play for the World Engine to act.

GPT World Engine commands — exactly one per assistant response: [say room] on its own line followed on the next line by the world/body event; [listening] to request the next observation; [wait] for passive listening; [tail] for the last ten retained observations; [history] or [history 2] for retained history. Untagged world-event replies are also supported. Do not enclose commands in code fences, add a trailing backslash, or use [bridge send].

With private-chat monitoring disabled or inactive, confirmed world events are posted to the API room and Nomi replies there. With monitoring active, private chat is read-only and GPT receives observations instead. Nothing is posted to Mary's private chat by this mode. Inspect the API checkpoint before retrying uncertain delivery; Reset does not undo earlier Nomi posts.

Using Heartbeat

Select one ChatGPT tab, enter the heartbeat phrase and the delay, then press Play. The bridge sends the phrase again after GPT completes each reply and the configured delay. GPT may reply with exactly [sleep] to stop Heartbeat, or [sleep 2HRS] to suspend it for two hours.

Heartbeat does not connect to Nomi or use any [bridge send], [say room], or group commands. Keep Edge running and the computer awake.
